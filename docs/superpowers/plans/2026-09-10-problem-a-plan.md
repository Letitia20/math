## 4. 第一问：固定圆柱预热平衡

### 4.1 数学模型

定义 r∈[0,R]，R=0.02 m，T 为绝对温度，C 为干基含水率。基准方程为

\[
\rho c_p T_t=\frac1r\partial_r(rkT_r),\qquad
C_t=\frac1r\partial_r(rD(C)C_r).
\]

参数：ρ=820 kg/m³，c_p=2600 J/(kg·K)，k=0.36 W/(m·K)，h_T=25 W/(m²·K)，h_m=8×10⁻⁷ m/s，D(C)=7×10⁻⁹ exp(−0.89/C) m²/s。

初始条件：T(r,0)=301.15 K，C(r,0)=2.55。

中心条件：T_r(0,t)=C_r(0,t)=0。

表面条件（外法向取正）：

\[
-kT_r(R,t)=h_T[T(R,t)-T_\infty(t)],
\qquad-D C_r(R,t)=h_m[C(R,t)-C_\infty(t)].
\]

该水分模型属于有效 Fick 模型；须在假设文档中明确 C 的质量基准及有效边界的含义。

### 4.2 执行步骤

- [ ] 从环形控制体积分推导离散通量，使中心单元不直接计算 1/r；明确表面是边界节点还是控制体面。
- [ ] 水分扩散保持散度形式，不能在 D 随 C 变化时直接写成 D 乘常系数拉普拉斯。
- [ ] 采用守恒型有限体积空间离散与隐式自适应时间积分，按局部状态更新 D。
- [ ] 输出网格与求解网格分开：题目每 0.1 cm 采样不代表内部计算网格必须同样粗。
- [ ] 计算 0–1800 s，提取表1、表2指定时刻和五个位置。

- [ ] 绘制中心与表面时间曲线、七个时刻径向剖面，解释温度与含水率传播速度差异。

### 4.3 验证与通过条件

### 7.2 守恒推导与备选模型

设 ρ_d 为单位当前体积的干物质质量，v 为固体骨架速度，j_w 为相对骨架的水分质量通量。在无干物质流失时，从

\[
\partial_t\rho_d+\nabla\cdot(\rho_d v)=0,
\]
\[
\partial_t(\rho_d C)+\nabla\cdot(\rho_d C v+j_w)=0
\]

得到 ρ_d(∂t C+v·∇C)=−∇·j_w。若采用 j_w=−ρ_d D∇C，则

\[
\frac{DC}{Dt}=\frac1{\rho_d}\nabla\cdot(\rho_d D\nabla C).
\]

这解释了为何干基含水率不能直接添加体积浓度的收缩浓缩项。题给经验密度和外加半径变化未必能同时满足干物质守恒；须核验，不可把 ρ/(1+C) 与几何演化各自独立代入后宣称严格守恒。

- [ ] 基准假设仅径向均匀收缩、长度保持 25 cm，骨架速度 v_r=(R'/R)r；说明附件只提供半径，轴向收缩无法唯一识别。
- [ ] 推导 ξ=r/R(t)∈[0,1] 的坐标变换，并同时变换材料导数、通量、表面边界和初始条件。
- [ ] 在上述均匀骨架运动下，坐标运动与材料对流项可相消；不能重复加入网格对流，也不能在缺少运动学假设时直接删去它。
- [ ] 若 ρ_d 空间均匀，基准水分式化为 C_t|ξ=R⁻² ξ⁻¹∂ξ(ξ D C_ξ)；非均匀时保留 ρ_d 权重。
- [ ] 把经验 ρ(C) 用于有效热容量，与守恒干物质密度的角色区分；检查总干物质量并说明经验式解释的限制。

- [ ] 所有输出空间位置在当时几何范围内，表面浓度与求解边界值一致。
- [ ] 对半径插值方式、几何运动假设及网格加密分别报告时长敏感性。

## 8. 统一数值验证与误差预算

- [ ] 分开记录空间离散、时间积分、输出插值和模型假设误差，不能用同一次比较替代全部验证。
- [ ] 径向区间数先比较 40、80、160，若未收敛继续至 320；收缩问题对归一化网格采用相同层级。
- [ ] 温度和含水率使用不同绝对容差与尺度；逐级收紧时间容差，记录求解器设置、最大步长、运行时间和失败信息。
- [ ] 在所有指定论文节点及代表性完整输出节点比较相邻精细网格；目标绝对差小于 5×10⁻⁵（对应各变量单位），并检查四位小数舍入是否稳定。舍入边界附近单独报告。
- [ ] 若目标精度达不到，继续细化或明确误差范围，不把相邻网格接近当作严格数学误差上界。
- [ ] 建立常物性无源平衡与通量积分基准；变物性热模型的物理能量账目必须按所选焓定义核查，不能直接把 ρc_pT 当成精确能量密度。
- [ ] 对基准可守恒问题，以相对总量误差 10⁻⁶ 为初始目标；接近零通量时改用绝对尺度，避免无意义的相对误差。
- [ ] 在 0.8、1.0、1.2 倍 h_T、h_m 下做单因素分析；明确这是探索性范围，不是数据支持的置信区间。
- [ ] 以另一种时间离散或独立常系数基准核验代表性场景；避免仅用同一实现的不同网格互相证明正确。
